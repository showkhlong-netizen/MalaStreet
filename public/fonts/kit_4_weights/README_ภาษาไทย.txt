MALA STREET — FOUR FONT WEIGHTS / ชุดตั้งค่าฟอนต์ 4 ระดับ

ปรับจากชุดเดิม 2 ระดับเป็น 4 ระดับ ตามลำดับจากบางไปหนาที่สุด:
1) บาง         = Prompt Regular (400)   — เหมือนตัวธรรมดาชุดเดิม
2) หนา         = Prompt Medium (500)    — เพิ่มใหม่
3) หนากลาง    = Prompt SemiBold (600)  — เพิ่มใหม่
4) หนามาก     = Prompt Bold (700)      — เท่ากับตัวหนาชุดเดิมและเป็นระดับหนาสุดที่ใช้

หมายเหตุ: คำว่า "หนา" และ "หนากลาง" เป็นชื่อระดับของร้าน โดยเรียงน้ำหนัก 500 < 600 < 700

วิธีใช้
- นำ mala-street-font.css ไปไว้ในโปรเจกต์และ import ในหน้าเว็บ
- ครอบเนื้อหาร้านด้วย class="mala-app" เพื่อไม่ให้ส่งผลไปหน้าอื่น
- เลือกระดับผ่าน class mala-font-thin, mala-font-bold, mala-font-mid-bold, mala-font-max-bold
- หรือใช้ font-weight: 400 / 500 / 600 / 700 ตามสถานการณ์
- เปิด preview.html ในเว็บเบราว์เซอร์เมื่อเชื่อมต่ออินเทอร์เน็ตเพื่อเทียบทั้งสี่ระดับ

ลิงก์ฟอนต์อย่างเป็นทางการ: https://fonts.google.com/specimen/Prompt
ลิงก์โหลดใน CSS: https://fonts.googleapis.com/css2?family=Prompt:wght@400;500;600;700&display=swap

ไฟล์ ZIP ไม่ได้แนบไฟล์ .ttf/.otf/.woff/.woff2; ใช้การอ้างอิง Google Fonts โดยตรง
สี ขนาด และ UI เดิมไม่จำเป็นต้องเปลี่ยนเพราะการเพิ่มระดับน้ำหนักฟอนต์
