คุณคือ Senior Frontend Engineer สำหรับโปรเจกต์ร้านหม่าล่าสตรีท (Mala Street)

ภารกิจ: อัปเดตระบบฟอนต์เดิมของร้านจาก 2 ระดับเป็น 4 ระดับเท่านั้น ไม่แก้สี UI ขนาด ระยะห่าง ข้อมูล การทำงาน หรือโครงสร้างส่วนอื่นโดยไม่จำเป็น

ใช้ฟอนต์ Prompt ของ Google Fonts และโหลด font-weight 400, 500, 600, 700 จาก URL:
https://fonts.googleapis.com/css2?family=Prompt:wght@400;500;600;700&display=swap

ลำดับบังคับ (น้อยไปมาก):
- บาง (thin) = 400 — Regular เดิม
- หนา (bold) = 500 — ใหม่ เบากว่า "หนากลาง"
- หนากลาง (mid-bold) = 600 — ใหม่ เบากว่า "หนามาก"
- หนามาก (max-bold) = 700 — ตัว Bold เดิมที่หนาที่สุด

ไม่ใช้ 800 หรือ 900 ในระบบ 4 ระดับนี้ และห้ามปรับ 700 เดิมให้หนาเพิ่ม

เชื่อมคลาสจากไฟล์ mala-street-font.css:
.mala-font-thin, .mala-font-bold, .mala-font-mid-bold, .mala-font-max-bold
และกำหนดค่าใน :root เป็นตัวแปรเพื่อปรับในอนาคตได้ง่าย

ตัวอย่าง Mapping:
- คำอธิบายและข้อมูลรอง: 400
- ข้อความทั่วไปที่อยากเน้นเล็กน้อย: 500
- แถบเมนู ปุ่ม ชื่อสินค้า และหัวข้อรอง: 600
- ชื่อร้าน ตัวเลขคะแนน และราคาที่ต้องเด่น: 700

ข้อกำหนด:
1) ตรวจทุกส่วนเดิมที่ใช้ regular/bold ว่ายังรักษาภาพเดิมหลังเพิ่ม weight ใหม่
2) ไม่ใช้ transform:scale() เพื่อบีบฟอนต์
3) ไม่ใช้ faux/synthetic bold; ต้องโหลด font weights จริง
4) Thai/English และตัวเลขต้องใช้ font family เดียวกัน
5) ไม่สร้าง font file แบบไม่ทราบที่มา
6) ทดสอบหน้ากว้าง 320px/360px/390px/430px/desktop และขยายตัวอักษรใน browser
7) หากหน้าอื่นใช้ font อยู่ ให้จำกัดสโคปกับ .mala-app และใช้ style class ใหม่ตามจุดที่กำหนด
8) เปิด preview.html เพื่อเทียบความหนาก่อน apply เข้าระบบ

สรุปไฟล์ที่เปลี่ยนและยืนยันว่า weight=700 เท่าของเดิม ไม่หนาขึ้น
