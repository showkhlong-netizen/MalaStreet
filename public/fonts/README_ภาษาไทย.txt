MALA STREET — ชุดตั้งค่าฟอนต์ Regular / Bold สำหรับเว็บไซต์

ฟอนต์ที่ประเมินว่าใกล้ภาพอ้างอิงที่สุด: Prompt
Regular (ตัวธรรมดา) = Prompt 400
Bold (ตัวหนา) = Prompt 700
ExtraBold (เผื่อหัวข้อหนากว่า) = Prompt 800

หมายเหตุ: ไม่สามารถยืนยันว่าเป็นฟอนต์ต้นฉบับ 100% จากภาพหน้าจอเพียงภาพเดียว เนื่องจากภาพไม่เก็บข้อมูลชื่อฟอนต์

ภายใน ZIP นี้ประกอบด้วย:
- mala-street-font.css : ติดตั้งฟอนต์บนเว็บไซต์ผ่าน Google Fonts
- preview.html : เปิดด้วยเว็บเบราว์เซอร์เพื่อเทียบหน้าตากับภาพต้นแบบและเลือก Prompt/Kanit
- ANTIGRAVITY_FONT_ONLY_PROMPT.txt : คำสั่งเปลี่ยนเฉพาะฟอนต์ใน Antigravity
- reference/reference-font.png : ภาพที่คุณส่งมาเพื่อใช้เทียบ
- OFFICIAL_DOWNLOAD_LINKS.txt : ลิงก์รับไฟล์ฟอนต์จริงจากผู้เผยแพร่

ZIP นี้ไม่มีไฟล์ฟอนต์ .ttf/.otf/.woff/.woff2 รวมอยู่ด้วย จึงต้องดาวน์โหลดไฟล์ฟอนต์เองจาก Google Fonts หากต้องการติดตั้งในเครื่อง ส่วนเว็บใช้งานได้เลยจาก CSS เมื่อเชื่อมต่ออินเทอร์เน็ต

วิธีใช้บนเว็บ
1. วางไฟล์ mala-street-font.css ไว้ในเว็บ เช่น /styles/mala-street-font.css
2. ใน HTML <head> ใส่ <link rel="stylesheet" href="/styles/mala-street-font.css">
3. ทุกข้อความจะใช้ Prompt และเลือก regular/bold ด้วย font-weight 400/700
4. เปิด preview.html บนเบราว์เซอร์ที่ต่ออินเทอร์เน็ต เพื่อดูการเทียบ Prompt กับ Kanit

แหล่งข้อมูลฟอนต์ Prompt: https://fonts.google.com/specimen/Prompt
